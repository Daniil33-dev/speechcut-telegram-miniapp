# Выбор сервисов: VPS, Vercel, OpenAI и OpenRouter

В исходном задании предусмотрен выбор инфраструктуры и языковой модели. Эти два решения независимы: OpenRouter можно использовать с VPS, а OpenAI — с Vercel. Исправления слов, пауз, загрузки и сохранения обязательны в любом варианте.

## Что готово в этом репозитории

| Вариант | Статус | Инструкция |
| --- | --- | --- |
| VPS + SQLite + приватный диск + OpenAI + AssemblyAI | Реализован и проверен | [Установка](INSTALL.md) |
| VPS + OpenRouter вместо OpenAI | Требуется новый LLM-адаптер и проверка | [OpenRouter](OPENROUTER.md) |
| Vercel + private Blob + Neon/PostgreSQL + Workflow + Sandbox | Проектная схема; адаптеры ещё нужно реализовать | [Облачная ветка](../deploy/VERCEL.md) |
| Vercel + OpenRouter | Требуются обе адаптации | Облачная ветка + OpenRouter |
| Vercel для интерфейса, VPS для API/worker/файлов | Возможная промежуточная схема, отдельно не проверена | Раздел ниже |

`APP_RUNTIME=vercel` или `LLM_PROVIDER=openrouter` сами по себе **не включают** эти варианты в текущем коде. Мастер-промпт должен сначала выяснить выбор пользователя, затем либо установить готовую VPS-ветку, либо реализовать недостающие адаптеры и проверить их. Отчёт VPS нельзя выдавать за приёмку Vercel.

## Где разместить приложение

**VPS.** Один сервер содержит web, отдельный worker, SQLite и приватные файлы. Подходит, если нужен контроль над FFmpeg, очередью, ресурсами и большим объёмом исходников. Нужно обслуживать ОС, диск, backup и HTTPS. Пошаговые команды уже есть в репозитории. Цена зависит от выбранного провайдера; существующий сервер можно использовать изолированно.

**Vercel без VPS.** Интерфейс/API — Vercel; видео — private Blob; состояние — Neon/PostgreSQL; оркестрация — Workflow; FFmpeg/VAD — Sandbox. Это проектная схема миграции, а не готовый deploy текущего каталога. Большие файлы загружаются напрямую в Blob, а состояния и версии не живут на локальном диске Function. Отдельно оцениваются storage, transfer, операции, вычисления и ресурсы Workflow/Sandbox. [План реализации](../deploy/VERCEL.md).

**Vercel + VPS.** Можно разместить только интерфейс на Vercel, сохранив API, авторизацию, SQLite, очередь и рендер на VPS. Тогда требуется явно настроенный API base URL, CORS только для своего UI, корректная передача Telegram initData и совместимая выдача медиа. Не переносите файл SQLite между двумя одновременно работающими хостами. Гибрид не устраняет стоимость и обслуживание VPS и не ускоряет автоматически его канал загрузки.

Если пользователь не знает, что выбрать, для установки именно готового кода предложите VPS. Если пользователь выбирает Vercel, следуйте облачной схеме, не подменяя его выбор покупкой VPS. Не настраивайте обе инфраструктуры одновременно без необходимости.

## Чем проверять и редактировать текст

**OpenAI API.** Уже реализован Responses-адаптер. Нужны свой API-ключ, доступная модель и баланс. Подписка ChatGPT не является API-балансом. Текущие акции/кредиты проверяются в своей организации по официальным условиям; активация и покупка не предполагаются автоматически.

**OpenRouter.** Альтернатива LLM, в том числе с бесплатными моделями `:free`. Нужны свой ключ, отдельный Chat Completions-адаптер, проверка русского текста, схемы JSON и учёта расходов. Предлагаемая в исходном задании `google/gemma-4-31b-it:free` присутствовала в [официальном каталоге](https://openrouter.ai/api/v1/models) 16 ноября 2026 года с нулевой ценой входа/выхода. Это проверка каталога, не качества монтажа. Наличие `response_format` не доказывает поддержку строгого JSON Schema у каждого endpoint. [Подробная инструкция](OPENROUTER.md).

`openrouter/free` — маршрутизатор разных бесплатных моделей, а не фиксированная Gemma. Не подключайте платный fallback без выбора пользователя. Бесплатная LLM не делает бесплатными ASR, сервер, хранение и передачу видео.

## Распознавание речи

AssemblyAI используется в готовом коде независимо от выбора LLM/хостинга. При отказе от него нужен отдельный ASR-адаптер: русская речь, настоящие word-level timestamps, стабильные ID, сохранение исходного transcript, usage и восстановление запросов. Самостоятельный ASR на сервере требует отдельной оценки CPU/GPU/RAM и качества выравнивания. Не заменяйте таймкоды приблизительным делением строки и не называйте другой ASR уже проверенным.

## Что спросить до установки

1. VPS или Vercel? Если VPS уже есть — адрес, SSH user, путь к ключу и домен, без содержимого ключа.
2. OpenAI или OpenRouter/free? Есть ли API-доступ и какой бюджет на реальные пробы?
3. Созданы ли свой бот и аккаунт AssemblyAI? Нужен личный доступ или несколько разрешённых ID?

Запрашивайте только отсутствующие ответы. Ключи вводятся в защищённую форму или приватный env. При выбранной альтернативе сначала составьте конкретный план адаптации из соответствующего документа; покупка ресурсов требует отдельного решения пользователя.
