# Как пользоваться

1. Откройте своего бота, нажмите `/start`, затем «Открыть монтаж».
2. Создайте ролик, выберите MP4/MOV/WebM/MKV до 500 МиБ и 15 минут. Дождитесь окончания передачи и проверки файла. После этого обработка продолжится на сервере без открытого приложения.
3. Проверьте сценарий. Удаление целого слова вырезает его речь; исправление написания меняет субтитры. Добавленный с нуля текст не озвучивается.
4. Для ИИ-правки введите, например, «убери повторы». Сначала посмотрите новый сценарий; при необходимости верните прежнюю версию.
5. Подтвердите нужную сохранённую версию. Выберите субтитры, их высоту и удаление пауз. Нажмите «Собрать видео».
6. Просмотрите результат и сохраните его.

## Сохранение

На iPhone: «Подготовить сохранение» → дождаться полного File → «Открыть меню сохранения» → «Сохранить видео», если устройство предлагает это действие. Отмена меню оставляет вас в приложении. Для больших файлов или устройства без file sharing используется нативная загрузка; сохранение в «Фото» в этом случае не гарантируется.

На компьютере: «Скачать видео». Файл получает штатный загрузчик Telegram 8.0+, обычно в папку «Загрузки». Telegram может запросить подтверждение или использовать выбранную в его настройках папку. Меню AirDrop не вызывается. Если Telegram устарел, обновите его.

Если ссылка истекла, нажмите «Обновить ссылку». Это не оплачивает новый монтаж. Обновление интерфейса после выпуска новой версии — через меню `⋯` Mini App.

## Отмена, расходы и хранение

Возврат к списку не отменяет обработку. Для отмены используйте соответствующую кнопку. Повтор операции сохраняет уже выполненные шаги, но неоднозначный сбой внешнего API может создать ещё один оплачиваемый запрос — это видно в расходах.

В «Расходы и хранение» показаны секунды ASR, токены OpenAI и известная оценка стоимости со всеми попытками. «Тариф уточняется» означает отсутствие подтверждённого тарифа.

Исходники и результаты остаются до ручного удаления. «Удалить ролик и файлы» удаляет всё задание, поэтому подтверждайте только нужный ролик. Текст может оставаться в резервной копии БД до конца срока её хранения. Ошибка удаления внешней копии требует сопровождения.
