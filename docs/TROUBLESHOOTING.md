# Если что-то не работает

Сохраните сценарий, безопасную ошибку и отчёт doctor. Не удаляйте исходник и не отключайте QA. Ошибка сохранения не требует нового рендера, ошибка рендера не требует нового ASR.

| Симптом | Проверка и действие |
| --- | --- |
| Mini App не открывается | DNS, HTTPS снаружи, APP_URL, BotFather/menu, health, 80/443. HTTP по IP недостаточен. |
| 401/403 | Запуск из своего бота, свежий initData, правильный Telegram ID в allowlist. После смены env перезапустить свои web/worker. Не включать dev auth в production. |
| Форма бота / сессия истекла | Setup ещё запущен, SSH tunnel активен; заново открыть 127.0.0.1:3079. Сохранённый токен не печатать, чужой webhook не перехватывать. |
| 413 / медленный большой файл | Proxy пропускает 8-МиБ часть (Caddy 9MB), хватает диска, сеть работает. Смотреть реальные байты и скорость; ASR/render измерять отдельно. |
| Не начинается обработка | systemd, heartbeat, очередь и lease. Не запускать второй worker в обход flock. |
| OpenAI 401/403 | Проверить срок ключа, проект/организацию, доступ к модели. Замена через закрытый env, сценарий сохраняется. |
| OpenAI 402/429 | Проверить API-баланс отдельно от подписки ChatGPT. Не делать бесконечные повторы. |
| Неподдерживаемая модель/параметр | Нужны Responses, JSON Schema и reasoning low. Другой провайдер не подключается одной заменой URL. |
| INVALID_PROOFREAD | Проверить отдельные токены, покрытие ID и названия. Повторять proofreading, сохраняя ASR и ledger. Не объединять предложение в узел. |
| WORD_CHECK_FAILED | Сохранить source-analysis/edit-map/word-audit/output-audit. Сравнить тихую речь с оригиналом, шумовой фон, VAD и звуковые пробы. Не обходить проверку. |
| PAUSE_CHECK_FAILED | Сначала вычесть поддержанную речь из кандидатов тишины, затем применять >300 мс. ASR spans не должны защищать секунды тишины. |
| Doctor / FFmpeg FAIL | Нужны subtitles/libass, zscale, tonemap, afftdn, libx264, AAC, VAD с правильным SHA и кириллический шрифт. |
| Worker killed / OOM | Журнал, лимит памяти, разрешение, диск и конкуренция. Один render за раз; не отдавать worker все ресурсы ОС без измерения. |
| На Mac меню AirDrop | Обновить Mini App через ⋯. Desktop должен показывать «Скачать видео» и использовать native download даже при наличии Web Share. |
| Отдельный плеер | Удалить href на MP4. Preview и attachment имеют разные подписи; inline document возвращает в приложение. |
| Нет «Сохранить видео» | Поддержка зависит от ОС/Telegram; File до 48 МиБ сначала готовится, затем нужен новый жест. Большие файлы передаются штатному загрузчику, который может сохранить в файловую папку. |
| Истекла ссылка | Обновить после авторизации без нового монтажа. |
| providerDeleted=false | Отдельно повторить удаление transcript у провайдера и проверить результат. Не заявлять полное удаление. |

Не прикладывайте личные записи и подписанные URL в публичные issues. Изменения алгоритмов проверяйте на разрешённом исходнике и регрессиях из [FIXES.md](FIXES.md).
