# Исправления, включённые в код и мастер-промпт

Версия публичного комплекта: 1.1.0, 16 ноября 2026 года. Здесь описаны воспроизведённые проблемы без личных записей, идентификаторов заданий и данных сервера.

| Проблема | Причина и исправление | Что сохранять при изменениях |
| --- | --- | --- |
| «Обычная фраза объединена в один узел» | LLM группировал несколько обычных слов. JSON Schema требует один токен; сервер проверяет покрытие, порядок и уникальность ID. Старую группу можно разделить только при точном совпадении токенов и ID. | Обычные слова редактируются по отдельности. Группа ID для единого названия сохраняет весь звук. Невалидные ответы не обходят проверку. |
| Ошибка границ слова при сборке | Фиксированный порог тишины терял тихие короткие слова, особенно в контексте громкой речи. Добавлены энергия 10-мс окон относительно шумового фона и подтверждение VAD/ASR. | Шумовой фон калибруется одинаково для исходника и результата. ASR-подсказка сама по себе не защищает растянутую тишину. |
| Паузы после слова оставались либо QA ложно их находил | Кандидат тишины пересекал тихую речь. Из него сначала вычитаются поддержанные речевые участки; порог >300 мс применяется к остаткам. | 299/300 мс не вырезаются, тихие слоги не считаются шумом. Не отключать pause QA. |
| Формально сохранены ID, но звук мог обрезаться | Одной карты ID недостаточно. Добавлено сравнение исходных и выходных звуковых проб каждого выбранного слова, с допуском на кодек. | Проверять звук, а не только число слов. Не выдавать автоматические метрики за прослушивание человеком. |
| Большой файл передавался медленно | Последовательная отправка частей заменена максимум тремя параллельными потоками, с ограниченными повторами отдельных частей. | Прогресс по фактически переданным байтам, скорость и ETA. Abort останавливает все запросы; complete только после их завершения. Рост скорости измерять отдельно от ASR/render. |
| После «Скачать в Файлы» открывался плеер без возврата | Навигационная ссылка на MP4 заменена платформенным сохранением. В UI удалены ссылки «Скачать в Файлы» и «Открыть страницу сохранения». Inline document-запрос возвращается в Mini App. | Никаких href на MP4 в save UI. Отдельная download-подпись, attachment и Range. Preview не ломать. |
| На Mac вместо скачивания появлялся AirDrop | macOS поддерживает Web Share, но это неудобный путь сохранения на компьютер. Desktop определяется до выбора способа. | macos/tdesktop → Telegram.downloadFile сразу из жеста, подпись «Скачать видео». iOS/iPadOS/Android сохраняют телефонный путь. |
| Длительная подготовка сбрасывала пользовательский жест | File готовится отдельно; системное меню запускается вторым явным нажатием. | До 48 МиБ в памяти, проверка полного размера/MIME, прогресс, отмена. Для больших файлов штатный загрузчик. |
| Отмена системного меню выглядела как ошибка монтажа | AbortError и отказ нативного диалога теперь нейтральны. | Повторить сохранение можно на том же экране без повторного рендера. Callback загрузчика не означает физическую запись файла. |
| Сессия формы подключения бота терялась | Состояние локальной формы сохраняется приватно, обработка ответов не уводит на пустую страницу. | При перезапуске сначала заново открыть форму; ключи не выводить, старого бота с чужим webhook не перехватывать. |
| Сбой рендера провоцировал повтор всех платных шагов | Checkpoint с rendererRevision и hash входов переиспользует ASR и версии; артефакт публикуется только после QA. | Повтор save/render не запускает ASR или новую правку. Сохранить ledger, прежние результаты и точную одобренную версию. |
| Неизвестный тариф мог выглядеть как бесплатный | Расход сохраняется сразу после ответа провайдера, до валидации текста; неизвестная стоимость остаётся null. | Все попытки учитываются; кэш не начисляется дважды; версии тарифов датируются. |

Дополнительно в рендере закреплены rotation/SAR/DAR, совместимый SDR-экспорт HDR, максимум две строки субтитров с измерением обводки, десятичные аргументы FFmpeg без scientific notation и ограниченное потребление памяти.

Результаты проверок и границы выводов — [ACCEPTANCE.md](../ACCEPTANCE.md). Эти исправления не гарантируют безошибочный монтаж любой записи или одинаковое сохранение на всех версиях Telegram.
